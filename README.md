# Beast Mode 90

A native Android 90-day home workout challenge app.

## Included
- 90-day workout schedule
- Push-ups, sit-ups, squats, planks and conditioning
- Build / Hard / Extreme difficulty
- Daily mission completion
- Recruit → Soldier → Ranger → Vanguard → Elite ranks
- Local progress saving with SharedPreferences
- Fitness tests on days 1, 29, 57 and 90
- 90-second rest timer
- Offline use
- No account, ads, analytics or network permission

## Build the APK
GitHub Actions builds an installable debug APK automatically after pushes to `main`.

Open **Actions → Build Beast Mode Android APK → latest successful run → Artifacts → BeastMode90-Android-APK**.

The extracted `app-debug.apk` can be installed on Android for personal testing.

## Safety
This is a demanding fitness template, not medical advice. Scale reps to your ability, use good form, warm up, keep recovery days, and stop for sharp pain, chest pain, faintness, or unusual shortness of breath.
